# 任务计划：分享网页笔记链接悬浮预览方案探索

## 目标
在不急于写代码的前提下，探索“分享网页笔记中鼠标悬浮到内部链接时显示对应文档预览，并支持默认钉住与快捷键关闭”的可落地前端方案，尽量满足付费用户的高便利性诉求。

## 已做决策
| 决策 | 理由 |
|------|------|
| 本轮只做方案探索，暂不写功能代码 | 用户明确“之探索方案不着急写代码” |
| 优先验证 Nuxt 客户端插件方案 | 用户建议该方向，且悬浮预览主要是浏览器交互能力 |
| 规划文件单独建新任务，原移动端阅读宽度计划保留不归档 | 本需求是新功能探索，不应覆盖旧任务证据 |
| 上一版自建 editorDom preview renderer 方案作废 | 用户明确指出应按页面思维；子文档已发布时，iframe 目标页面是最直接预览载体 |
| 新方案优先使用 iframe 加载目标分享页 | 复用现有页面渲染、权限、主题和资源处理能力，避免重复造预览渲染器 |
