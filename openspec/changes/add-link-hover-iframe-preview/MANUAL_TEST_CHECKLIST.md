# 链接悬停预览手动测试清单

## 基本功能
- [X] 将鼠标悬停在块引用链接上会在延迟后显示预览
- [X] 将鼠标悬停在指向内部文档的普通链接上会在延迟后显示预览
- [X] 预览正确显示目标文档内容
- [X] 预览显示文档标题（启用时）
- [X] 点击链接仍然正常导航
- [X] 按 Escape 键关闭预览
- [X] 点击关闭按钮关闭预览
- [X] 点击“打开全文”在新标签页中打开完整页面

## Preview Mode 显示
- [X] 预览 iframe 隐藏头部
- [X] 预览 iframe 隐藏底部
- [X] 预览 iframe 隐藏左侧边栏（文档树）
- [X] 预览 iframe 隐藏右侧边栏（大纲/AI）
- [X] 预览 iframe 隐藏文章元信息栏
- [X] 预览 iframe 仅显示内容（和可选标题）
- [X] 正常页面（不带 `?preview=1`）显示所有 UI 元素

## 边界情况
- [X] 受密码保护的文档在预览中显示密码表单
- [X] 可以在预览 iframe 内验证密码
- [X] 密码验证后，“打开全文”保留 key 参数
- [X] 过期文档在预览中显示过期状态
- [X] 未分享文档在预览中显示未分享状态
- [X] 不存在的文档在预览中显示未找到状态
- [X] 外部链接不会触发预览
- [X] 跨域链接不会触发预览
- [X] iframe 加载超时会显示“预览加载超时或被安全策略阻止”提示
- [X] iframe 被 CSP/X-Frame-Options 阻止时可点击“打开全文”降级

## Sticky 行为
- [X] 鼠标离开链接和预览区域后预览自动关闭（默认不 sticky）
- [X] 点击图钉后预览进入 sticky 状态，鼠标离开链接后仍然可见
- [X] 再次点击图钉后取消 sticky
- [X] 悬停在另一个链接上将预览切换到新目标
- [X] 导航到不同路由时预览关闭
- [X] 图钉按钮显示在关闭按钮 `×` 左侧
- [X] 长标题不会挤压“打开全文 / Esc 关闭 / 图钉 / 关闭”按钮
- [X] 桌面端预览头部标题区域显示移动语义指针，并可拖拽移动预览框
- [X] 点击头部按钮区域不会触发拖拽

## 移动端/响应式
- [X] 预览在桌面浏览器上正常工作
- [X] 预览适应移动视口（< 768px）
- [X] 触屏设备上不阻断正常链接导航
- [X] 触屏设备不启用标题栏拖拽
