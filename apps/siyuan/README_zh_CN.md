# 在线分享

您的自部署 notion 替代品

## 在整体架构中的角色

`apps/siyuan` 是这个产品体系里的免费版创作端前端。

它以思源插件形式存在，负责在宿主思源内部完成内容创作与触发分享。

它不是带 server 能力的查看页。
它也不是收费版 / 专业版创作端。

收费版 / 专业版创作端叫 `share-pro`，不在这个仓库里。
收费版 / 专业版后端叫 `siyuan-note-service`，也不在这个仓库里。

在免费链路里，`apps/siyuan` 直接和宿主思源内核以及本地 public 文件交互。
也就是说，免费创作链路没有本仓库自带的业务后端参与。
